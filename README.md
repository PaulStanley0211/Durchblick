# Durchblick

Durchblick is a web-based ETF comparison tool for intermediate German retail investors who already invest through Sparpläne but want more confidence in their choices: side-by-side metrics, after-tax outcomes under German tax rules, and plain-language explanations for every number. Status: pre-code — planning artifacts are complete, implementation has not started. See [PLAN.md](PLAN.md) for the authoritative scope, architecture, and decision spec.
